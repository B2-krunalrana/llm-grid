01 —

Introduction

LLM Grid is an open-source, fully local application developed by Krunal Rana. It provides a unified interface to access and interact with multiple AI language model (LLM) providers using your own API keys — running entirely on your own device.

This Privacy Policy is unusually short for a reason: there is almost nothing to disclose. LLM Grid has no server, no database, no user accounts, and no telemetry system. We have architected the application from the ground up to ensure that your data never leaves your device and never passes through any infrastructure we own or operate.

The Short Version: We don't collect your data. We can't collect your data. LLM Grid has no mechanism to do so. What you do inside LLM Grid stays entirely on your machine.

03 —

API Keys & Credentials

To use LLM Grid, you provide API keys from third-party AI providers (such as OpenAI, Anthropic, Google, Mistral, etc.). These keys are stored exclusively on your own device — in your browser's local storage or your local filesystem, depending on how you run the application.

Your API keys never touch our servers. LLM Grid has no server-side component. When you submit a prompt, your browser or local application makes a direct API call to the AI provider of your choice — LLM Grid acts purely as a local interface layer that never intercepts, logs, or stores the request or response.

Practical implications:

  • Your API keys are never transmitted to Krunal Rana, LLM Grid, or any party other than the specific AI provider you direct your request to.
  • If you clear your browser data or uninstall the application, your API keys are permanently deleted — we have no copy.
  • You are responsible for generating, managing, rotating, and revoking your API keys directly with each provider.
  • Use your browser's built-in password manager or a dedicated secrets manager for additional protection of stored API keys.
04 —

How Your Data Flows

Understanding exactly how data moves when you use LLM Grid is important. The flow is direct and simple:

Your Device → AI Provider's API → Your Device

That is the complete data path. LLM Grid sits on your device as a local interface. It reads your input, formats the API request using your stored API key, sends it directly from your machine to the AI provider, receives the response back on your machine, and displays it. At no point does any request or response pass through any server, proxy, or infrastructure owned or operated by LLM Grid.

What this means in practice:

  • LLM Grid never acts as a proxy or middleware between you and your AI provider.
  • No request content, response content, metadata, or timing data is logged anywhere by us.
  • Your conversation history (if saved) is stored only on your local device.
  • Clearing your browser/app data completely wipes all LLM Grid data — permanently and irreversibly.
  • We have no ability to recover, restore, or export your data because we never had it.

06 —

Local Storage

LLM Grid may write data to your browser's localStorage or IndexedDB, or to your local filesystem (for desktop/CLI versions). This local storage may include:

  • Your API keys (encrypted where possible using browser-native APIs).
  • UI preferences, selected providers, and configuration settings.
  • Conversation history (only if you enable this feature — off by default).
  • Model parameters and custom system prompts you have configured.

All of this data exists exclusively on your device. It is never synced, backed up, or transmitted to any external server. You can view, export, or delete this data at any time through your browser's developer tools or the application's settings panel.

Full Control: Clearing site data in your browser settings removes every trace of LLM Grid's local storage instantly and permanently. We have no copy and cannot restore it.

No Analytics, No Tracking

LLM Grid does not include any analytics, tracking, or telemetry code. Specifically:

  • No Google Analytics, Mixpanel, Amplitude, or similar tools.
  • No crash reporting services (Sentry, Bugsnag, etc.).
  • No session recording tools (Hotjar, FullStory, etc.).
  • No advertising pixels or retargeting scripts.
  • No A/B testing frameworks that communicate with external servers.
  • No CDN-based font or script loading that creates tracking opportunities (all assets are bundled).
  • No cookies of any kind — not essential, not preference, not analytics.

You can verify this by inspecting the application's network requests in your browser's developer tools. You will see only direct calls to the AI provider APIs you have configured — nothing else.

08 —

Security

Because LLM Grid stores your data locally, the security of that data depends primarily on the security of your own device. We recommend:

  • Keep your operating system and browser updated to receive security patches.
  • Use a device with full-disk encryption enabled.
  • Do not use LLM Grid on shared or public computers where others may access your browser's local storage.
  • Use API keys with the minimum required permissions and set spending limits where providers allow.
  • Regularly audit and rotate your API keys from each provider's dashboard.

On our end, LLM Grid's open-source codebase is publicly auditable on GitHub. Anyone can inspect the code to verify that no hidden data transmission exists. We welcome security disclosures via the GitHub repository or contact email.
